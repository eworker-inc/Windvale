# Earliest-known combined-scope claim evidence

- Review date: 2026-07-30
- Claim owner: [E-Worker Inc](https://eworker.ca)
- Status: Dated public-search record; not a claim that Windvale is the first project in any individual category

## Purpose

Windvale describes itself as among the earliest known publicly developed efforts to build its own language, compiler, verified bytecode, runtime, assembler, object model, linker, native path, Foundation library, and operating system as one coherent AI-authored stack from an empty project.

This record preserves the meaning and reasonable search basis of that qualified statement. It does not establish an exhaustive priority result. Private, deleted, unpublished, poorly indexed, or differently described projects may exist, and public projects may change after the review date.

## Claim boundaries

The statement concerns the combined project scope, not priority for an operating system, language, compiler, virtual machine, assembler, linker, library, or AI-authored repository individually. A close comparison would need public evidence of:

- an original source-language semantic contract;
- a compiler and both portable verified bytecode/runtime and native paths;
- an assembler, structured object model, and linker owned as distinct contracts;
- a reusable foundation library and a planned or implemented operating system using the same stack;
- repository-wide AI implementation and documentation authorship under human direction and review; and
- public source publication as one coherent project developed from an empty starting repository.

The word “known” limits the statement to reasonably discoverable public evidence as of the review date. “Among the earliest” deliberately permits earlier and contemporaneous efforts and makes no exact ranking claim.

## Search method

The review used general web and GitHub repository searches combining terms such as `AI-authored`, `written by AI`, `operating system`, `programming language`, `compiler`, `bytecode`, `runtime`, `assembler`, `object model`, `linker`, `standard library`, `self-hosting`, and `from scratch`. Candidate descriptions and repository READMEs were inspected for their stated authorship model and technical scope.

This is a negative-search problem, so the method cannot prove that no earlier project exists. Its purpose is to support careful qualified wording and to make close comparisons visible rather than ignored.

## Close and adjacent public efforts

| Project | Publicly stated scope | Relationship to the Windvale claim |
| --- | --- | --- |
| [LPC4 Full-Stack](https://github.com/LPC4/Full-Stack) | A source language, complete compiler, assembler, object linker, RISC-V virtual machine, self-hosted guest tools, standard library, and interactive OS. | A close contemporaneous combined-stack comparison. Its public README does not establish Windvale's particular portable verified-bytecode/host-adapter contracts or the same repository-wide AI-authorship policy. Its existence is one reason Windvale says “among” rather than “the first.” |
| [Felix OS / FSOL](https://github.com/benzenma123/FSOL) | A custom language and Rust-hosted compiler producing x86-64 assembly for a bootable kernel, with NASM and GNU `ld` in the build. | A language-and-OS comparison with a narrower documented toolchain boundary. Its README does not claim the full Windvale contract set or repository-wide AI authorship. |
| [SlopOS](https://github.com/SlopLabs/slopos) | A substantial from-scratch Rust operating system described as fully designed and written by AI agents. | Strong evidence that earlier or contemporaneous AI-authored operating-system projects exist. It does not present an original language, portable bytecode/runtime, assembler, object model, linker, and Foundation library as the same end-to-end stack. |
| [Bitwise](https://github.com/pervognsen/bitwise) | A human-led educational effort to build a language, software toolchain, hardware, and eventually an operating system from scratch. | Important earlier prior art for coherent from-scratch computing stacks, but not a repository-wide AI-authored project and not the same software contract set. |

## Maintenance rule

Do not strengthen this wording to “first” without substantially broader, independently reviewable evidence. If a materially comparable earlier project is found, record it here and reassess the public claim. Ordinary project progress does not require rerunning the search; refresh this record when the claim is used in significant promotion, when a close comparison is discovered, or when its date would create a misleading impression.
