# Decision 0371: Windvale-owned native file-input leaves

- Status: Accepted current-host normal-path C# emitter removal; Linux execution and grouped qualification pending
- Date: 2026-08-08
- Advances: [Decision 0370](0370-Windvale-Owned-Native-File-Output-Leaves.md) and [Decision 0057](0057-Windvale-Native-Execution-And-Dotnet-Retirement.md)
- Contract: [Windvale native execution context](../../Specifications/Windvale-Native-Execution-Context.md#runtime-private-file-input-table)

## Context

The native `file.read_bytes` service already performs host I/O without a
managed callback, but one 719-line C# source still constructed and patched its
complete Windows and Linux x86-64 leaves whenever a service bundle was
assembled. Those leaves have stable identities and an independently tested
snapshot/cache contract, so live managed instruction emission retained a
duplicate implementation owner in the normal runtime.

File input is the largest remaining platform leaf family. It validates names,
returns exact ordinal cache hits, enforces the 64-snapshot and 4 MiB bounds,
opens and reads host files, detects oversize streams, publishes immutable
descriptors, closes handles, and maps contained platform failures. That logic
needs focused source phases and exact differential evidence, not one replacement
monolith.

## Decision

- Add one shared Windvale module for descriptor publication, platform error
  mapping, failure detail, and branch helpers. Add one focused Windows module
  and one focused Linux module for their established machine contracts.
- Organize the platform modules by entry, name validation/open, read
  preparation, immutable publication, and return phases. Keep the label and
  patch orchestration in the owning platform module so branch invariants remain
  visible. Individual functions stay reviewable even though the platform
  modules remain cohesive.
- Add one small bridge that returns the Windows leaf followed by the Linux
  leaf. Retain its exact WVB for reconstruction, differential execution,
  qualification, and Stage 0 recovery, and require the ordinary native project
  front door to reproduce it.
- Embed only the two generated `.bin` leaves in `Runtime/Windvale.Native`.
  The normal runtime selects and verifies the exact platform leaf; it neither
  embeds nor executes the generator WVB.
- Remove C# instruction emission, label dictionaries, relative-branch
  patching, cache/descriptor emission, and platform error mapping. Preserve the
  runtime-private `WVFI` table, ABI registers, snapshot semantics, exact limits,
  failure details, service-bundle placement, and both leaf identities.

## Evidence and consequences

The affected construction test was reviewed before execution. It compiles and
pins the builder, shared code, both platform cores, and bridge; compares the
retained bridge byte for byte; runs it through the reference interpreter and
verified x86-64 backend; compares all 2,214 generated bytes with the two
pre-cutover artifacts; proves the runtime does not embed the bridge; and
reconstructs it through the ordinary native source front door.

The final focused Fast selection passes 1/1 in 3.254 seconds after a Release
build that succeeds with zero warnings and errors in 12.35 seconds. Both
qualification scripts pin the source, bridge, and leaf identities; only their
syntax is checked in this slice. The existing real-file/snapshot behavior test
was not rerun because the leaf bytes, `WVFI` table owner, and behavior contract
did not change. No Development, Standard, Qualification, grouped cross-host,
or real Linux gate was run.

The managed source is reduced from 719 lines of emitter and patching logic to a
90-line exact artifact selector and verifier. Managed ownership now begins at
platform file-input/output-table binding, service-bundle assembly,
executable-memory ownership, contexts, arenas, and invocation rather than at
platform leaf instruction construction.

## Reconsideration triggers

Change either leaf identity only through an explicit file-input adapter
contract and complete descendant qualification. Keep the bridge WVB until the
final digest-bound Stage 0 archive exists. Replace the managed selector only
when a native host owner enforces the same platform choice, authorization,
snapshot/table validation, exact identity, and W^X publication boundary.
