# Windvale support

Windvale is an active pre-1.0 research and development project without a support service-level agreement.

For reproducible bugs, use the repository bug-report form. For design proposals, use the proposal form. For usage and development questions, use the question form or GitHub Discussions if discussions are enabled. Search existing documentation and reports first.

Include the source commit, operating system, architecture, .NET SDK version, exact command, relevant diagnostics, and the smallest safe reproducer. Do not attach secrets, private source, credentials, or unnecessarily large generated artifacts.

Only the current `main` branch is under active development until a release defines a supported-version window. Help is provided as maintainer capacity permits and is not guaranteed.

Use [SECURITY.md](SECURITY.md) for vulnerabilities and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns. Do not put confidential details in a public support request.
