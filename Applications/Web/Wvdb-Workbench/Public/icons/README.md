# WVDB Workbench icon provenance

The source PNG was generated for Windvale on 2026-08-20 with OpenAI's built-in
image generation. The prompt requested a polished, transparent, text-free square
application icon combining a dark navy database cylinder with a cyan/teal valley
and wind mark. The 192 px and 512 px assets are high-quality bicubic reductions
of `wvdb-workbench-source.png`.
