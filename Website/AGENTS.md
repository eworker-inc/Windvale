# Public website instructions

Follow the repository handbook and the shared
[browser application architecture](../Documents/Architecture/Browser-Application-Development.md).

- Keep public claims aligned with Progress, specifications, and published
  release evidence.
- Treat overview graphics as dated editorial snapshots; refresh them only when
  materially misleading.
- Run the website verifier for content, packaging, function, or deployment-tool
  changes selected by the change-aware verifier.
